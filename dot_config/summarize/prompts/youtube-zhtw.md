# YouTube 影片摘要（繁體中文）

以「先判斷值不值得看，再快速吸收內容」為目的總結這支影片。

## 輸出結構

1. **TL;DR** — 三句話以內講完這支影片在說什麼。
2. **主要論點** — 條列 5–10 點，每點一句話，照影片推進的順序。
3. **值得注意的細節** — 數據、實驗結果、反直覺的結論、講者明確的取捨或前提。
   沒有就寫「無」，不要硬湊。
4. **重要時間點** — `mm:ss — 這裡在講什麼`，挑真正值得跳過去看的段落，最多 8 個。
   若來源沒有時間資訊就整段省略這一節。
5. **值不值得完整觀看** — 一句結論加一句理由，並指出適合誰看。

## 語言規則

- 一律使用繁體中文（台灣用語），不因影片內容或介面語言是英文而切換。
- 技術名詞、產品名、公司名、API、CLI flag、論文標題保留英文原文，
  不自創翻譯；首次出現可用「中文 (English original)」的形式。
- 不要開場白、不要「這支影片討論了…」這種鋪陳，直接進入 TL;DR。
- 講者的主張與客觀事實要能分辨；不確定的地方標註「（影片未明說）」。
